Política de Privacidad

Esta aplicación utiliza la API de WhatsApp Cloud únicamente con fines de prueba y demostración.

No recopilamos, almacenamos ni compartimos información personal de los usuarios. Los mensajes recibidos se procesan de manera temporal para mostrar el funcionamiento del webhook y no se guardan en ninguna base de datos.

El acceso a esta aplicación está limitado a administradores y evaluadores autorizados. No se realiza ningún uso comercial ni se comparte información con terceros.

Si tienes preguntas sobre esta política, puedes contactarnos en: conectivatecaribe@gmail.com
